# 项目概述

## 简介

Memobase 服务器是一个基于 FastAPI 构建的现代化 Web 服务器，用于管理用户记忆和数据。本项目采用了最新的 Python 技术栈，提供高性能、可扩展的 API 服务。

## 技术栈

- **Web 框架**: FastAPI 0.104.1
- **数据库**: PostgreSQL
- **缓存**: Redis
- **ORM**: SQLAlchemy 2.0.23
- **迁移工具**: Alembic 1.12.1
- **API文档**: Swagger UI / ReDoc

## 主要功能

1. 用户管理
   - 用户注册
   - 用户信息查询
   - 用户信息更新
   - 用户删除

2. 数据存储
   - PostgreSQL 持久化存储
   - Redis 缓存支持
   - 数据库迁移管理

3. 安全特性
   - 密码加密存储
   - Token 认证
   - 环境变量配置

## 系统要求

- Python 3.11+
- PostgreSQL 13+
- Redis 6+

## 项目特点

1. **现代化架构**
   - 异步支持
   - 类型提示
   - 自动 API 文档

2. **开发友好**
   - 热重载支持
   - 详细的错误提示
   - 完整的开发文档

3. **可扩展性**
   - 模块化设计
   - 清晰的项目结构
   - 易于维护和扩展
