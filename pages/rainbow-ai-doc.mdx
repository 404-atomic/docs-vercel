## 已识别的技术栈与作用

根据已审阅的文档，提及或建议了以下技术：

* **Rust:** 主要的后端编程语言。因其高性能、内存安全、并发能力而被选中，适合构建复杂、高性能的 AI 中央意识核心和七翼系统。
* **SurrealDB:** 推荐的主要数据库。因其多模态存储、图数据库特性以及处理 AI 状态、关系、记忆、任务等复杂关联数据的潜力而被选中。
* **Svelte / Next.js:** Web 客户端界面的潜在前端框架。用于构建现代化的、响应式的用户界面。
* **Flutter:** 用于构建跨平台（iOS/Android）移动客户端界面的潜在框架，可通过单一代码库实现。
* **Langchain (或类似库):** 建议用于连接和管理与各种大型语言模型 (LLM) 交互的库/框架。
* **NATS (或类似消息队列):** 建议的消息队列系统。可能用于模块间的异步通信、处理后台任务（如自省）、提高系统弹性和可伸缩性。
* **Axum / Actix Web:** 被提及的潜在 Rust Web 框架，用于构建后端 API 服务。
* **Docker / Kubernetes (K8s):** 被提及用于未来可能的部署、微服务管理和扩展。
* **MCP (模块化能力协议):** 被提及的一种协议，用于集成可供 AI 调用的外部工具（如图像生成）。
