## 技术架构详解

### 1. API路由层
```
src/app/api/auth/
├── register/
│   └── route.ts  # 处理注册请求
└── login/
    └── route.ts  # 处理登录请求
```

#### 路由职责
- 接收HTTP请求处理
- 执行基础请求验证
- 调用控制器处理业务
- 返回标准化响应

### 2. 控制器层
```
src/lib/auth/controllers/
├── register.controller.ts  # 注册业务逻辑
└── login.controller.ts     # 登录业务逻辑
```

#### 注册控制器职责
1. 验证数据完整性
2. 检查邮箱唯一性
3. 执行密码加密
4. 创建用户记录
5. 触发注册事件

#### 登录控制器职责
1. 验证登录凭证
2. 检查账户状态
3. 验证密码正确性
4. 创建用户会话
5. 触发登录事件

### 3. 数据流转流程

#### 注册流程
1. HTTP请求 → register/route.ts
2. route.ts → register.controller.ts
3. 控制器 → 数据库操作
4. 返回处理结果

#### 登录流程
1. HTTP请求 → login/route.ts
2. route.ts → login.controller.ts
3. 控制器 → 验证凭证
4. 创建会话并返回

### 4. 安全考虑

#### 路由层安全
- 请求方法验证
- 输入数据净化
- 访问频率限制

#### 控制器层安全
- 数据完整性校验
- 业务规则验证
- 安全策略执行
