# AI Agent

![目标执行流程](../../src/目标执行流程.png)

执行流程说明：
1. 用户输入目标/提示
2. 协调器接收并转发给规划器
3. 规划器确定所需工具和参数
4. 执行器按计划执行任务
5. 结果通过协调器返回
6. 最终结果反馈给用户
